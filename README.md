# محاسبه‌گر بهای تمام‌شده واردات

سایت ایستا برای محاسبه‌ی هزینه‌های گمرکی و بهای تمام‌شده‌ی واردات، با پشتیبانی از **رویه گمرکی** و **رویه ملوانی**.

بدون build، بدون npm، بدون فریم‌ورک. فقط HTML و CSS و JavaScript خالص — مستقیم روی GitHub Pages بالا می‌آید.

---

## انتشار روی GitHub Pages

1. محتویات این پوشه را در ریشه‌ی مخزن قرار بده و push کن.
2. در مخزن برو به **Settings → Pages**.
3. در بخش **Source** گزینه‌ی **Deploy from a branch** را انتخاب کن.
4. شاخه را روی `main` و پوشه را روی `/ (root)` بگذار و **Save** بزن.
5. یکی دو دقیقه بعد آدرس `https://<username>.github.io/<repo>/` بالا می‌آید.

هیچ Action یا مرحله‌ی build لازم نیست. فایل `.nojekyll` هم گذاشته شده تا Jekyll در فایل‌ها دست نبرد.

### اجرای محلی

چون کد از ES Modules استفاده می‌کند، باز کردن مستقیم `index.html` با دابل‌کلیک کار نمی‌کند و باید از یک سرور ساده استفاده کنی:

```bash
python3 -m http.server 8000
# سپس http://localhost:8000
```

## ساختار فایل‌ها

```
index.html                 اسکلت صفحه
.nojekyll                  غیرفعال‌کردن پردازش Jekyll
assets/
├── styles.css             تمام استایل‌ها + اسکرول افقی جدول‌ها
└── js/
    ├── app.js             رندر و اتصال رویدادها
    ├── calc.js            موتور محاسبه — بدون وابستگی به فریم‌ورک
    ├── constants.js       مقادیر پیش‌فرض و نام رویه‌ها
    ├── clearanceRows.js   ردیف‌های پیش‌فرض مراحل ترخیص
    ├── fields.js          تعریف ورودی‌های فرم
    ├── format.js          فرمت اعداد و پارس ورودی
    └── dom.js             کمک‌کننده‌های کوچک DOM
```

`calc.js` هیچ وابستگی به مرورگر ندارد و در Node هم اجرا می‌شود:

```bash
node -e "import('./assets/js/calc.js').then(async m => {
  const { DEFAULT_INPUT } = await import('./assets/js/constants.js');
  const { DEFAULT_CLEARANCE_ROWS } = await import('./assets/js/clearanceRows.js');
  console.log(m.compute({ ...DEFAULT_INPUT, rows: DEFAULT_CLEARANCE_ROWS, scenario: 'disc' }).perUnit);
})"
```

## قواعد محاسبه

### ارزش گمرکی

```
ارزش گمرکی = نرخ ارز × ارزش اظهار + کرایه بین‌المللی + بیمه [+ مبلغ بیمه‌نامه]
```

### ماخذ

| رویه | فرمول |
|---|---|
| گمرکی بدون تخفیف | `ماخذ کل` |
| گمرکی با تخفیف | `حقوق ورودی + سود بازرگانی × (۱ − درصد تخفیف)` |
| ملوانی | `حقوق ورودی × ۸۰٪ + سود بازرگانی × (۳۰٪ تولید داخل \| ۱۵٪ سایر)` |

`سود بازرگانی = ماخذ کل − حقوق ورودی`

### حقوق و عوارض

```
حقوق ورودی        = ارزش گمرکی × ماخذ
پایه              = ارزش گمرکی + حقوق ورودی
ارزش افزوده       = پایه × ۱۰٪   (ملوانی: ۵٪)
عوارض جنگی        = پایه × ۱٫۲٪
مالیات علی‌الحساب  = پایه × ۲٪
```

مالیات علی‌الحساب ردیف مستقل است و داخل ماخذ نمی‌آید.

### سه کرایه، سه رفتار متفاوت

| کرایه | مسیر | داخل ارزش گمرکی؟ |
|---|---|---|
| کرایه حمل بین‌المللی (CFR / CPT) | مبدأ تا کشور همسایه یا بندر | بله — ماخذ رویش اخذ می‌شود |
| کرایه لنج | کشور همسایه تا ایران | خیر — ردیفی در هزینه‌های ترخیص، فقط در رویه ملوانی |
| کرایه حمل زمینی | بوشهر تا تهران | خیر — جزو هزینه‌های ترخیص |

### بهای تمام‌شده

```
بهای تمام‌شده = خرید کالا + جمع صورت رویه + هزینه‌های ترخیص + پسماند
هر واحد       = بهای تمام‌شده ÷ تعداد
حاشیه سود     = فروش هر واحد ÷ بهای تمام‌شده هر واحد − ۱
```

---

## تفاوت‌ها با فایل اکسل اولیه

1. **هزینه‌ی ترخیص بر تعداد واحد تقسیم می‌شود.** در فایل اصلی مبلغ کل ترخیص به هزینه‌ی *هر واحد* اضافه شده بود.
2. **تخفیف روی کل زنجیره اعمال می‌شود.** با کاهش ماخذ، پایه‌ی ارزش افزوده و عوارض و مالیات هم کوچک‌تر می‌شود.
3. **حاشیه سود** `فروش ÷ بهای تمام‌شده − ۱` است، نه نسبت خام.
4. **ماخذ ملوانی محاسبه می‌شود** و دیگر سلول خالی نیست.
5. **کرایه لنج از مبنای مالیاتی خارج شد**، چون در اظهار نمی‌آید. جای آن در هزینه‌های ترخیص است و فقط وقتی رویه ملوانی فعال باشد سرشکن می‌شود؛ هرگز با رویه گمرکی جمع نمی‌شود.

## نکات

- واحد پول (تومان یا ریال) فقط برچسب است و در محاسبه اثر ندارد.
- ورودی‌ها ذخیره نمی‌شوند؛ با رفرش صفحه به مقادیر پیش‌فرض برمی‌گردند.
- مقادیر پیش‌فرض در `assets/js/constants.js` است. اگر مخزن را عمومی می‌کنی، بهتر است این اعداد را به مقادیر خنثی تغییر بدهی.
